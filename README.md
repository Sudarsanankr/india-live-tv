# India Live TV

A free-to-build Android starter app with a dark live-TV interface, channel search, category filters, and an HLS-capable player (Media3).

## Important
The channel list is a UI starter. Stream URLs are intentionally blank. Add only official/public streams you are authorized to redistribute or embed. The app does not include paid-channel or unauthorized IPTV links.

## Build APK for free with GitHub Actions
1. Create a new GitHub repository named `india-live-tv`.
2. Upload all files and folders from this ZIP to the repository root.
3. Open the repository's **Actions** tab and enable workflows if GitHub asks.
4. Choose **Build Android APK** → **Run workflow**.
5. When the run finishes, open it and download the `India-Live-TV-debug-apk` artifact.
6. Extract the ZIP on your Android phone and install `app-debug.apk`. You may need to allow installation from your browser/file manager.

This produces a debug APK for testing, not a Play Store release.
